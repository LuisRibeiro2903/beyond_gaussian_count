# Release status

Prepared for public use as a thesis research companion, version 1.0.0. This
task prepares the content and pushes it to the private repository; it does not
change GitHub visibility or claim a DOI.

Completed release work:

- Author-approved MIT licence for original contributions; explicit per-file
  upstream terms, notices, licence texts and source-aligned attribution.
- Exclusion of 183 raw Campus/Sci-Art camera-payload files from the public tree
  and replacement of the initial private packaging history with clean history.
  The old history is backed up locally outside this repository.
- Recorded numerical packages and trace identities preserved. Source recovery
  and unrecoverable historical versions disclosed without changing old results.
- Isolated evidence installation and CPU test installation checked; GPU smoke
  test checked on the recorded hardware/toolchain. The detailed validation
  record is `release/public_validation.json`. CI repeats portable checks.
- Whole-tree and reachable-history publication checks, including licence
  coverage, excluded-payload absence and credential-pattern scanning.

The supported scope is numerical evidence inspection, empirical figure
regeneration, synthetic tests and documented implementation use. Full original
paper reruns, commercial rights to restricted upstream portions, redistribution
of datasets/models, recovery of every historical dirty runtime, and a DOI are
not promised. These are explicit boundaries, not hidden release prerequisites.
See `REPRODUCIBILITY_LIMITS.md` and `LICENSE_REVIEW.md`.

Before citing: use the actual GitHub URL and immutable public release commit or
tag. If an archive is created later, add only its real assigned identifier.
