# What the companion establishes

The public companion supports independent inspection of recorded numerical
results, regenerated empirical figures, synthetic correctness tests, and use
of the provided implementation with separately acquired licensed inputs.
It does not claim to recreate every original paper experiment or every byte
of the historical development workspace.

## Numerical evidence

The twelve selected benchmark packages retain their original summaries,
protocols, validation gates and compressed per-frame traces. Reproduction,
project extension, synthetic control, negative finding and superseded timing
states remain distinct. Hash checking establishes identity, not scientific
correctness by itself. The empirical figure generator independently checks
the numerical relationships it plots against saved records.

## External inputs

Images, pretrained scene PLYs, locally trained hierarchies and binary oracle
arrays are not distributed. Campus/Sci-Art camera payloads are also excluded.
Original hashes and reconstruction scripts identify what is needed without
claiming the bytes are included. A trained hierarchy cannot generally be
recreated byte-for-byte merely by repeating training. Existing dataset access
conditions continue to apply. No paper-reported FPS ranking follows from these
project measurements.

## Historical runtime identity

Original manifests and protocol amendments identify the executed clean commit
or individual file hashes. The release snapshot includes the available working
implementation and explicit [historical source-coverage records](../release/historical_source_coverage.json).
The clean canonical CityGaussian revision's 42 tracked Python files have been
recovered under `reproduction/source_snapshots/`. The final natural ALoD-Exec
campaign's seven effective sealed files match the current snapshot. Five source
versions from the earlier natural association campaign were not recovered.
The companion does not
silently label all dirty historical execution states as recoverable. Missing
old source versions limit exact historical replay; they do not prevent checking
the preserved numerical tables and traces. The release's own Git commit is a
packaging identity, separate from every executed experiment identity.

## Scope of availability statements

A suitable appendix statement is:

> The accompanying repository provides the project implementation, validation
> and benchmark tools, and the numerical evidence supporting the reported
> analyses. It records the upstream revisions, applied patches, input hashes,
> and reproduction procedures. Third-party datasets, scene models, and
> restricted raw camera payloads must be obtained or reconstructed separately;
> the repository documents the limits of exact historical replay.

Add an actual repository URL and immutable release commit when citing it.
A DOI is optional and must only be stated after a reviewed archive exists.
The repository is prepared for public visibility; this task does not itself
change its GitHub visibility or create a DOI.
